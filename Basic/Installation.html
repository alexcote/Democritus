DEMOCRITUS

Do I need to install anything to run Democritus?

No. Unlike the original 2000 edition, Democritus no longer requires Java runtime plugins, Shockwave Flash, or manual font installations. It runs entirely within standard modern web browsers using native HTML5 and JavaScript.

However, Democritus is built as a Progressive Web App (PWA). You can install it onto your computer, tablet, or phone to run offline in a distraction-free window without browser address bars or navigation controls.

How to Install as an App

Android (Chrome / Samsung Internet / Firefox)

  1. Open Democritus in your browser.
  2. Tap the browser menu (three dots ⋮ in the top right).
  3. Select Add to Home screen or Install App.
  4. The atom icon will appear on your device's home screen and app launcher.

Windows, macOS & Linux (Chrome / Edge / Brave)

  1. Look at the right side of your address bar for the Install App icon (a monitor with a down arrow).
  2. Click it and select Install.
  3. Democritus will launch in its own standalone window and add a desktop/launcher shortcut.

iPhone & iPad (Safari)

  1. Open Democritus in Apple Safari.
  2. Tap the Share button (a square with an upward pointing arrow).
  3. Scroll down and tap Add to Home Screen, then tap Add.
